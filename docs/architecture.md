# Architecture

The authoritative, company-level architecture for NEXORA is
[`NEXORA-PLATFORM-ARCHITECTURE.md`](NEXORA-PLATFORM-ARCHITECTURE.md). It
defines the vision, principles, layer model, Core services, Product Registry,
identity model, domain/routing rules, tech stack, environments, security
model, data architecture and the phased build plan.

This file is a stub required by that document's own Appendix B; it exists so
the path `/docs/architecture.md` resolves. Do not duplicate content here —
extend the platform architecture document instead, and record any decision
that constrains future work as an ADR under [`adr/`](adr).

`ADR-0001 — Core Architecture Model`, which the platform document extends,
is the standards-repo baseline referenced throughout
(`copilot-instructions.md`, `architecture.agent.md`). If it is not yet present
in this repository, treat it as external until it is imported or superseded
by an ADR recorded here.
