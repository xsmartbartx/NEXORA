# Architecture Decision Records

One file per decision that constrains future work, named
`ADR-NNNN-kebab-title.md` (Appendix A of
[`../NEXORA-PLATFORM-ARCHITECTURE.md`](../NEXORA-PLATFORM-ARCHITECTURE.md)).

The backlog of ADRs implied by the platform architecture is tracked in §16 of
that document (`ADR-0002` through `ADR-0012`). Write each one before or during
the phase it depends on — not in advance, and not after the fact.
